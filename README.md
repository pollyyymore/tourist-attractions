# 1 Проект

Каталог туристических мест

## 2 Назначение проекта

Каталог туристических мест позволяет пользователям просматривать популярные туристические места.

## 3 Целевая аудитория

Туристы и люди, планирующие свой отпуск.

## 4 Предметная область

Предметная область проекта будет включать:

- дизайн;
- программирование;
- наполнение контентом;
- тестирование.

## 5 Основные сущности

- место
- регион
- категория
- описание

## 6 Основные функции

### 6.1 Пользователь

- регистрация;
- авторизация;
- выход из аккаунта;
- просмотр и редактирование профиля;
- изменение пароля.

### 6.2 Каталог мест

- просмотр каталога туристических мест;
- поиск конкретного места;
- сортировка мест;
- фильтрация по региону;
- просмотр подробной информации о месте.

### 6.3 Место

- описание места;
- категория места;
- фотография места.

### 6.4 Оценки и отзывы

- выставление оценки места;
- редактирование своего отзыва;
- написание отзыва;
- удаление отзыва.

### 6.5 Роль Администратор

- добавление и редактирование места;
- управление регионами и категориями;
- удаление некорректных материалов;
- управление пользователями;

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
