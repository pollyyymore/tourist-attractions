# TourCatalog — каталог туристических мест

## Назначение

TourCatalog — консольное приложение для ведения каталога туристических мест
и формирования личного списка избранного для посещения.

Приложение позволяет:

- просматривать места каталога;
- находить места по названию;
- фильтровать места по региону, категории и рейтингу;
- сортировать места по рейтингу;
- добавлять новые места в каталог;
- просматривать пользователей каталога;
- добавлять пользователей;
- проверять доступность места на определённую дату;
- добавлять места в избранное;
- отменять записи избранного;
- просматривать список избранного;
- получать статистику по категориям и средний рейтинг каталога;
- хранить данные между запусками приложения.

## Целевая аудитория

Путешественники и туристы, которым необходимо вести личный каталог
интересных мест и планировать их посещение.

## Предметная область

Основными объектами предметной области являются:

- место (туристическое место);
- пользователь;
- запись избранного.

Пользователь может добавлять туристические места в личный список
избранного на определённые даты. Одно место не может иметь двух
активных записей избранного на одну и ту же дату. Отменённая запись
не блокирует место и позволяет добавить его повторно на эту дату.

## Основные сущности

### Place — туристическое место

Объект `Place` представляет туристическое место в каталоге.

Основные атрибуты:

- `id` — уникальный идентификатор места;
- `name` — название;
- `region` — регион, в котором находится место;
- `category` — категория (гора, озеро, музей, парк, водопад);
- `description` — краткое описание;
- `rating` — рейтинг места (от 0 до 5).

Основные методы:

- `matches_query()` — проверка, встречается ли подстрока в названии места;
- `has_rating_at_least()` — проверка, что рейтинг не ниже заданного значения;
- `__str__()` — строковое представление места;
- `from_data()` — создание объекта `Place` из набора данных (classmethod);
- `validate_rating()` — проверка допустимого диапазона рейтинга (staticmethod).

### User — пользователь

Объект `User` представляет пользователя каталога.

Основные атрибуты:

- `id` — уникальный идентификатор пользователя;
- `name` — имя пользователя;
- `email` — адрес электронной почты.

Основные методы:

- `__str__()` — строковое представление пользователя;
- `from_data()` — создание объекта `User` из набора данных (classmethod).

### Favorite — запись избранного

Объект `Favorite` представляет запись о добавлении места в избранное
пользователем на определённую дату.

Основные атрибуты:

- `id` — уникальный идентификатор записи;
- `place` — объект `Place`, связанный с записью;
- `user` — объект `User`, связанный с записью;
- `visit_date` — дата посещения в формате ISO (YYYY-MM-DD);
- `is_cancelled` — признак отмены записи.

Основные методы:

- `cancel()` — отмена записи (изменяет состояние, не удаляя объект из коллекции);
- `__str__()` — строковое представление записи с учётом состояния.

## Основные операции

### Работа с местами

- добавление места;
- поиск места по названию;
- фильтрация мест по региону;
- фильтрация мест по категории;
- фильтрация мест по рейтингу;
- сортировка мест по рейтингу;
- просмотр списка мест;
- получение среднего рейтинга каталога;
- получение статистики по категориям.

### Работа с пользователями

- создание пользователя;
- поиск пользователя по имени или email;
- просмотр информации о пользователях.

### Работа с избранным

- добавление места в избранное;
- проверка доступности места на дату;
- отмена записи избранного;
- просмотр списка избранного.

При добавлении места в избранное проверяется наличие другой активной
записи этого же места на ту же дату. Отменённая запись не блокирует
место и позволяет добавить его повторно.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

- `data/places.json`;
- `data/users.json`;
- `data/favorites.json`.

При загрузке данные из JSON преобразуются в объекты `Place`, `User`
и `Favorite`. При сохранении объекты преобразуются обратно в данные JSON.

Для связи записи избранного с местом и пользователем в `favorites.json`
используются их идентификаторы `place_id` и `user_id`.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

- запуск приложения;
- отображение меню;
- получение данных от пользователя;
- организацию пользовательских сценариев.

### `models/places.py`

Содержит класс `Place` и функции работы с местами:

- `add_place()`;
- `find_place()`;
- `find_place_by_id()`;
- `filter_by_region()`;
- `filter_by_category()`;
- `filter_by_rating()`;
- `sort_places()`;
- `get_average_rating()`;
- `get_categories_stat()`;
- `show_places()`.

### `models/users.py`

Содержит класс `User` и функции работы с пользователями:

- `add_user()`;
- `find_user()`;
- `find_user_by_id()`;
- `show_users()`.

### `models/favorites.py`

Содержит класс `Favorite` и функции работы с избранным:

- `is_place_available()`;
- `add_to_favorites()`;
- `cancel_favorite()`;
- `get_favorite_status()`;
- `show_favorites()`.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразование:

- JSON → объекты Python;
- объекты Python → JSON.

Основные функции:

- `load_places()` / `save_places()`;
- `load_users()` / `save_users()`;
- `load_favorites()` / `save_favorites()`.

### `utils.py`

Содержит вспомогательные функции:

- `input_int()` — безопасный ввод целого числа;
- `input_float()` — безопасный ввод дробного числа;
- `input_date()` — безопасный ввод даты;
- `input_non_empty()` — безопасный ввод непустой строки.

### `tests/`

Содержит автоматизированные тесты проекта:

- `test_places.py` — тесты класса `Place` и функций работы с местами;
- `test_users.py` — тесты класса `User` и функций работы с пользователями;
- `test_favorites.py` — тесты класса `Favorite` и функций работы с избранным.

## Запуск приложения

Для запуска приложения выполнить:

```text
python main.py
```

После запуска отображается главное меню.

## Тестирование

Для запуска автоматизированных тестов выполнить:

```text
pytest -v
```

Тесты проверяют:

- создание и работу объектов `Place`, `User` и `Favorite`;
- методы классов (`matches_query`, `has_rating_at_least`, `cancel`, `validate_rating`);
- операции с местами (поиск, фильтрация, сортировка, статистика);
- операции с избранным (проверка доступности, отмена);
- корректное создание объектов из данных (метод `from_data()`).
