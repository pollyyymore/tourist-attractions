# Каталог туристических мест

Консольное приложение для ведения каталога туристических мест
и формирования личного списка избранного для посещения.

## Возможности

- просмотр, поиск и сортировка мест по рейтингу;
- фильтрация по региону, категории и минимальному рейтингу;
- добавление новых мест в каталог;
- добавление и удаление мест в списке избранного;
- просмотр среднего рейтинга и статистики по категориям;
- сохранение всех данных в JSON-файлах.

## Сущности проекта

- **Место** — название, регион, категория, описание, рейтинг;
- **Регион** — территориальная привязка места;
- **Категория** — тип места (гора, озеро, музей, парк, водопад);
- **Избранное** — список мест для посещения с указанием даты.

## Структура проекта

- `main.py` — точка запуска и меню;
- `places.py` — работа с каталогом мест;
- `favorites.py` — работа с избранным;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.10+
- pytest
- flake8

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    pytest

## Проверка качества кода

    flake8 --exclude venv .
